# 카나다라 (KANADARA) — CM · AG 오토캐시백 거래 승인 · 전표 · 정산 관리 웹앱 (목업 사이트)

PRD, 기능명세서, 유저플로우(2026-10-30)를 기반으로 실제 동작하는 상태 관리와 시나리오별 더미 데이터가 탑재된 반응형 웹 애플리케이션입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 으로 접속합니다.

## 주요 구현 기능 및 추천 테스트 시나리오

1. **인증 및 역할별 접근 격리 (`1.1`, `1.2`)**
   - 역할별 허용 메뉴 분리, AG별 담당 CM 배정 변경 시 거래·정산 조회 범위 실시간 반영, 권한 밖 거래 상세 URL 직접 접근 차단(403 보안 안내).
2. **CM 승인 요청 등록 및 표준 거래 조건 매칭 (`2.1`, `2.2`)**
   - 카드사 × 거래 방법 선택 시 활성화된 조건만 동적 노출, 카드번호·주민등록번호 형식 검증 및 자동 마스킹, 조건 수정 시 기존 접수 거래 스냅샷 보존.
3. **AG 승인 검토 · 카드사 신청 기록 · 승인/반려 확정 (`3.1`)**
   - `TRX-202610-0016` (요청대기) → `검토 시작` → `카드사 신청 내역 기록` → `승인` 또는 `반려(필수 사유 입력)` 처리 및 상태 역전 차단.
4. **CM 매출전표 제출 및 Google Sheets 자동입력 · 중복 방지 재처리 (`5.1`, `5.2`)**
   - `TRX-202610-0011` (승인 완료·전표 대기)에서 김민준 CM으로 전표 제출 → 구글 시트 외부 행 ID 자동 부여 및 **실시간 시트 뷰어** 반영.
   - `TRX-202610-0009` (OAuth 토큰 만료 실패 더미 건)에서 AG/관리자가 멱등키(`거래ID:전표ID`) 중복 대조 후 재처리 실행.
5. **월별 거래내역 및 CM 수수료 정산 집계 · 파일 추출 (`6.1`, `6.2`)**
   - 기준 월(`2026-10`, `2026-09`) 및 마감일 선택, CM별 집계·적용 산정 기준·집계 제외 사유 확인.
   - `TRX-202610-0007` (법인 특약 수수료율 미확정 건)을 통한 **산정 데이터 누락 사전 오류 안내** 및 수수료율 확정 후 Excel 호환 UTF-8 CSV 정산 파일 다운로드.
6. **CM 내 거래 목록 합산 예상 수수료 및 행별 예상 수수료 표시**
   - CM 화면 `내 거래 목록` 상단에 승인 요청 접수된 모든 건을 합산한 **내 승인 요청 합산 예상 수수료** 요약 배너와 거래 진행에 따른 변동 가능 안내 문구 제공.
   - 목록 내 각 거래의 신청 금액 하단에 `32,000,000원 / 캐시백 1.75% / 예상수수료 153,600원` 형식으로 직관적 표기.
7. **구글 시트 연동 기반 카드사별 비동기 거래 조건(실행일자 기준) 업데이트**
   - `/admin/conditions` (`거래 조건 · 시트 연동`) 화면에서 진행경로(`AG다이렉트` 등), 카드종류, 금액구간, 선수금 비율, 할부개월 조건 및 **실행일자(`effectiveFrom`)** 버전 관리.
   - **새 조건 실행일자 전까지 이전 조건 자동 유지**, `실행일자 시뮬레이터` 및 AG 승인 시 **거래승인일자 기준 실행 조건 자동 전환**(`TRX-202610-0016` 삼성카드 `11/02` vs `11/05` 승인일 비교), 구글 시트 원클릭 동기화·TSV 붙여넣기·최적화 마스터 시트 CSV 다운로드 지원.
